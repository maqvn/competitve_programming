Está cada vez mais difícil conseguir uma vaga nos cursos do Centro de Informática (CIn)! Considerando a enorme quantidade de interessados, o sistema atual não consegue gerar a lista de aprovados dentro do tempo necessário. A Diretoria do CIn depende de você para implementar um algoritmo mais eficiente.

O curso de Ciência da Computação (CC) possui 100 vagas, divididas em duas entradas com 50 vagas cada. O mesmo se aplica ao curso de Engenharia da Computação (EC). Já o curso de Inteligência Artificial (IA) possui 50 vagas, divididas em duas entradas com 25 vagas cada. Inicialmente, os candidatos de cada curso são ordenados pela nota do Exame Nacional (EN). Havendo empate nas notas, o primeiro critério de desempate consiste na idade dos candidatos (da maior para a menor idade). Havendo empate nas idades, o segundo e último critério de desempate é o momento da inscrição (de quem se inscreveu primeiro para quem se inscreveu por último).
Input

A primeira linha contém 0 < q ≤ 10.000 a quantidade de candidatos aos cursos do CIn. Em cada uma das próximas q linhas, tem-se o nome do candidato (0 < |nome| ≤ 30 caracteres, sem espaço, tabulação ou quebra de linha), o curso de interesse (curso = CC ou EC ou IA), a nota obtida (um inteiro não-negativo 0 ≤ nota ≤ 1000) e a idade do mesmo (um inteiro não-negativo). Os candidatos são listados por ordem de inscrição (do primeiro para o último). Não há candidatos diferentes com o mesmo nome.
Output

Para cada curso, imprima a lista de aprovados em cada entrada, bem como a nota de corte do curso. Se um curso não tiver candidatos aprovados, imprima "?" (sem as aspas) no lugar do valor da nota de corte (i.e., "nota de corte = ?", sem aspas). Imprima primeiro os dados do curso de CC, depois os dados do curso de EC, por fim, os dados do curso de IA.
